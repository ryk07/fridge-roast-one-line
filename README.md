An entry for the [Fridge Roast: One Line, Biggest Laugh](https://make.fun/c/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) bounty on make.fun.

`main.py` (stdlib only) writes one original roast of a smart fridge — at most
200 characters — to `/output/entry.txt`:

> My smart fridge pushed a firmware update at 3 a.m. — now the ice maker won't work until I accept the terms, and the milk expired while I was still scrolling.

Run it with `python3 main.py`. It is deterministic: two runs from different
working directories produce byte-identical output.
